## 摘要
AIVC（AI Virtual Cell，人工智能虚拟细胞）是一种学习得到的跨条件细胞行为模拟器。预测细胞群体在转录层面对遗传扰动的响应是一项核心任务。Perturb-seq 通过破坏性测序记录该响应，因此对照细胞与扰动细胞永远不会以配对形式被观测到，且同一条件下的细胞仍具有异质性和噪声。对单个细胞进行回归会将采样变异吸收到估计效应中，而可解释性需要可重复的群体效应。P2P（Perturbation-to-Perturbation，扰动到扰动）以随机细胞集合视图作为监督单元。从同一条件中抽取的两个视图共享可重复的群体效应，并通过视图特异性变异而不同。置换不变集合编码器汇总对照群体，结构化编码器表示扰动 token、细胞背景、剂量和组合交互，门控机制将经验条件效应记忆与神经残差融合。异方差头预测群体均值和逐基因响应方差。在统一协议和五个随机种子下，相对于 GenePert、LinearPert、SLIM、Scouter 和 scPILOT，P2P 在 Adamson、Norman、Replogle K562 和 Replogle RPE1 的每一个数据集上均取得最低的表达 RMSE 以及最高的 Effect Pearson、DEG F1 和 DEG 平均精度。在 Replogle K562 上，相对于在这两项指标上均为最强基线的 Scouter，Effect Pearson 从 0.643 提升至 0.702，DEG F1 从 0.067 提升至 0.178。

## Abstract
AIVC (AI Virtual Cell) is a learned simulator of cellular behavior across conditions. Predicting how a cell population responds transcriptionally to a genetic perturbation is a core task. Perturb-seq records that response by destructive sequencing, so a control cell and a perturbed cell are never observed as a pair, and cells under one condition remain heterogeneous and noisy. Regression on individual cells absorbs sampling variation into the estimated effect, whereas interpretation requires the reproducible population effect. P2P (Perturbation-to-Perturbation) takes a stochastic cell-set view as its supervision unit. Two views drawn from the same condition share a reproducible population effect and differ by view-specific variation. A permutation-invariant set encoder summarizes the control population, a structured encoder represents perturbation tokens, cellular context, dose, and combination interactions, and a gate blends empirical condition-effect memory with a neural residual. A heteroscedastic head predicts the population mean and gene-wise response variance. Under one protocol and five seeds, P2P attains the lowest expression RMSE and the highest Effect Pearson, DEG F1, and DEG average precision on each of Adamson, Norman, Replogle K562, and Replogle RPE1 relative to GenePert, LinearPert, SLIM, Scouter, and scPILOT. On Replogle K562, Effect Pearson rises from 0.643 to 0.702 and DEG F1 rises from 0.067 to 0.178 relative to Scouter, the strongest baseline on both metrics.

## 1. 核心问题与整体含义（研究动机与背景）

- **任务背景**：AIVC（AI 虚拟细胞）旨在跨条件模拟细胞行为，其核心子任务是预测细胞群体在**遗传扰动**（CRISPRi/CRISPRa 等）下的转录组响应。
- **数据困境**：Perturb-seq 依赖破坏性测序，**对照细胞与扰动细胞不可能被同一时刻配对观测**；同一条件内的细胞仍存在细胞周期、应激状态、捕获效率等异质性噪声。
- **建模范式问题**：
  - 若在**单细胞层面**做回归，模型会把采样变异（sampling variation）误吸收进扰动效应估计，得到不可重复的“伪效应”。
  - 而生物学解释真正需要的是**可重复的群体效应**（population effect），即扰动群体均值与匹配对照群体均值之差。
- **关键概念区分**：论文明确区分三种量——单细胞状态（一个表达向量）、群体均值（一个条件的统计量）、扰动效应（两群体均值之差）。P2P 优化后两者，细胞级观测仅用于构造集合统计量。
- **核心命题**：把“随机细胞集合视图”而非“单个细胞对”作为监督单元，从非配对、异质的群体数据中直接学习条件级效应。

## 2. 方法论

### 2.1 核心思想：跨视图群体去噪（Cross-View Population Denoising）

- 对同一条件（对照集 $X_{0,s}$ 与扰动集 $X_{p,s,d}$）各自随机切分出两个视图 $X^a, X^b$。
- 两视图共享**同一可重复的群体效应**，仅采样噪声不同；因此可用一个视图去监督由另一视图预测出的群体统计量。
- 训练时执行双向预测（$X^b_0 \to X^a_p$ 与 $X^a_0 \to X^b_p$）并交叉配对（crossed pairs），权重 0.25；**从不假设某细胞与另一细胞一一对应**。

### 2.2 技术组件

- **置换不变集合编码器（SetEncoder）**
  - 逐细胞共享投影：线性层 + LayerNorm + GELU + Dropout。
  - 打分网络给出归一化注意力权重 $a_i$；集合状态由注意力加权均值 $\bar h_a$ 与无权重的离散度 $\bar h$、方差 $v$ 共同构成，经 MomentMLP 融合。
  - 所有操作对细胞置换对称，$v$ 保留群体异质性信息；无权均值锚定对照基线。
- **结构化扰动与背景编码**
  - 带 mask 的 token 平均池化（padding 不贡献），支持单基因与多基因组合。
  - 组合条件额外加一个 pair-interaction MLP 非线性修正 $q(e_p)$（单 token 时关闭）。
  - 背景嵌入 $E_s[s]$ 与剂量 MLP $r(d)$ 相加后 LayerNorm。
- **记忆门控效应预测**
  - 融合集合状态与条件状态得 $h_{cond}$，经 DeltaHead 得神经残差 $\Delta_{neural}$。
  - 对训练角色细胞计算经验记忆 $m = \text{mean}(X^{role}_p) - \text{mean}(X^{role}_0)$。
  - 学习标量门 $g=\sigma(\alpha)$（$\alpha$ 初始化为 1.1，即记忆分支初始权重约 0.75），$\hat\delta = g\,m + (1-g)\Delta_{neural}$，$\hat\mu = \text{mean}(X_0) + \hat\delta$。
- **异方差输出头**
  - 预测逐基因 log 方差并裁剪到 $[-8, 4]$；可采样 $\tilde Y = \hat\mu + \epsilon\exp(\tfrac12\log\hat\sigma^2)$，采样均值再中心化到 $\hat\mu$。
- **效应中心的跨视图目标（Eq. 14）**
  - $L = 0.35 L_{nll} + 1.50 L_\Delta + 0.15 L_{corr} + 0.08 L_{mom} + 0.05 L_{cv}$
  - $L_\Delta$：基因加权 Smooth L1（权重 $w_g = 1 + |\delta_g|/\text{mean}_k|\delta_k|$，抑制大量无变化基因主导方向）。
  - $L_{corr}$：中心化效应向量的相关性项。
  - $L_{mom}$：对数空间匹配预测方差与目标视图经验方差。
  - $L_{cv}$：两方向预测的均值与 log 方差一致性（在采样前计算，与 $\epsilon$ 无关）。
- **群体解释（Eq. 15）**：若视图误差条件均值为零、两次抽样同分布，则 $E[\bar y_v]=\mu_{p,s,d}$，$E[\bar y_v - \bar c_v]=\delta_{p,s,d}$，即跨视图监督无偏地指向目标群体的**一阶矩**。

## 8. 局限与不足

### 8.1 方法层面的局限

- **仅对齐一阶矩**：Eq. 15 的无偏性论证只针对群体均值（及均值差）。模型对群体**方差、协方差、分布形状**没有同等的理论保证；异方差头预测的是逐基因边缘方差，未建模基因间相关结构，因此不能直接用于需要联合分布的下游任务（如群体级采样、基因模块协同响应模拟）。
- **依赖匹配对照的存在**：训练与推断都假定每个 context 有可用的对照集 $X_0$。对于缺乏同批次对照、或对照本身受扰动（如处理组背景差异大）的场景，$\hat\mu = \text{mean}(X_0) + \hat\delta$ 的加性分解会继承对照基线偏差。
- **“群体效应”粒度的固有上限**：方法有意放弃细胞级对应，因此无法回答“某个细胞在扰动后会变成什么”这类反事实单细胞问题，也不能刻画响应异质性亚群（如仅 5% 细胞强响应）。虽然集合编码器保留了方差 $v$，但监督信号本身是均值差，模型没有动力去恢复响应亚群结构。
- **记忆分支的适用边界**：门控记忆项 $m$ 依赖训练角色细胞的经验均值差，对训练期未出现或样本极少的条件，记忆退化为噪声，实际由 $\Delta_{neural}$ 承担；论文未系统给出“记忆何时有效/何时有害”的判别准则。
- **组合扰动的泛化未经检验**：pair-interaction MLP 只在 Norman 的双扰动上评估，且消融显示该模块影响最大，说明性能对该模块较敏感；对未见基因对的零样本组合外推、以及三基因以上组合，没有实验支撑。
- **超参数较多且集中**：损失权重（0.35/1.50/0.15/0.08/0.05）、门控初值 1.1、方差裁剪区间 $[-8,4]$、基因权重定义等均为固定值，未做敏感性分析，跨数据集迁移时是否需要重调不明。

### 8.2 评估层面的局限

- **基线未同栈重训**（前文已述），且缺少 scGen、CPA、GEARS、scGPT 等更强/更新的对照，难以判断增益中有多少来自方法本身、多少来自训练协议差异。
- **消融覆盖面窄**：仅在 RPE1 单数据集上做组件消融，且未报告消融的多种子方差，无法判断小幅度差异（如移除 heteroscedastic head 后 Effect Pearson 由 0.6609 升至 0.6681）是否显著。
- **预处理阈值敏感**：80 细胞过滤、5,000 HVG、DEG 判定阈值（FDR ≤ 0.05 且 $|\delta| \ge 0.1$）都会显著改变任务集与指标绝对值，论文未给出这些选择的敏感性曲线。
- **词表 transductive**（前文已述）使测试条件的 token 在训练期已可见，真实冷启动场景下的表现可能低于报告值；memory-assisted transfer 实验也不能等同于零样本迁移。
- **统计检验缺失**：报告了均值 ± 样本标准差，但未做配对显著性检验或效应量估计，跨方法的“全面最优”在部分指标上差距较小，缺少统计支撑。

## 9. 启发与可拓展方向

- **把无偏性从一阶矩推广到二阶矩**：可引入跨视图的协方差/分布匹配项（如 sliced Wasserstein、MMD 或相关矩阵 Frobenius 损失），使模型输出具备群体级联合分布意义，从而支持“模拟一个扰动群体的整体流形位移”。
- **监督单元的一般化**：双视图交叉监督本质是“同一潜在群体统计量的两个噪声观测”，这一框架可迁移到其他无法配对的群体比较问题，如不同时间点、不同组织切片、不同测序平台间的群体效应估计。
- **不确定性向下游传导**：现有异方差头给出的逐基因方差可与 DEG 判定结合，做基于后验的“差异基因概率”而非硬阈值，可能进一步提升 DEG AP 与可解释性。
- **与单细胞反事实方法互补**：P2P 提供可靠的群体级锚点，可作为细胞级生成模型（CPA/scGen 类）的约束项，缓解后者把采样噪声误学为效应的老问题。
- **组合扰动的结构化先验**：pair-interaction 模块目前是无约束 MLP，若引入基因通路/PPI 先验或低秩假设，可能改善未见基因对的组合外推，并让交互项本身具备生物学可读性。

## 10. 总体评价

P2P 的价值主要不在架构复杂度，而在**问题重述的准确性**：它把“对照与扰动细胞无法配对”这一数据事实，转化为“同条件双视图共享同一群体效应”的监督构造，并用群体一阶矩的无偏性给出了清晰的理论交代。方法模块（置换不变集合编码、mask 池化 + 交互项、记忆门控、异方差头）均服务于这一目标，工程实现也控制在了单卡可复现的范围内。

其实证强度体现在 4 个 Perturb-seq 基准、5 个种子、表达/效应/DEG 三层指标的全面覆盖，尤其在大样本 Replogle 屏幕上相对基线的增益幅度较大且方向一致。主要短板在于：基线未同栈重训且对比集合偏旧、消融只在单数据集完成、词表构造与迁移实验存在乐观偏差、以及理论上只保证一阶矩而无分布级保证。

综合来看，该工作适合被定位为**群体级扰动效应估计的强基线**：在“需要可重复的群体均值差、且存在匹配对照”的场景下可信度高；而在需要单细胞反事实、联合分布采样、或严格零样本组合外推的场景下，需谨慎外推其结论。
