## 摘要
单细胞基础模型通常将每个基因视为一个词元，这既昂贵又浪费。一个细胞可表达数千个基因，因此每个基因一个词元会使自注意力计算代价高昂；然而其中许多基因检测水平较低，携带的信号太少，不足以单独占用一个词元。共同表达的基因可以改为共享一个词元，而为那些突出的基因保留单独词元。我们提出 scTAT（转录组感知分词），将基因集词表与逐细胞分词器相结合。该词表包含在预训练语料中稳定共现且相对表达稳定的重叠基因集。使用这些基因集会带来两个困难。第一，哪些基因应共享一个词元取决于细胞，而现有多基因词元会预先固定分组。第二，不同大小的基因集必须与单个基因在同一尺度上比较。因此，分词器逐细胞进行决策，在按基因集大小的平方根归一化的表达分数下，让基因集与单个基因竞争词元位置。训练仍然重建单个基因，因此预测保持基因分辨率。在冻结嵌入的细胞类型注释中，scTAT 以一半的词元预算匹配最强的一个基因一个词元模型。在相同预算下，其相对于一个基因一个词元模型的优势随着预算缩小以及分词器为基因集分配更多位置而增大。用基因集词元编码相同基因还几乎将 Transformer 的矩阵乘法成本减半。这些结果表明，一个词元不必恰好对应一个基因：当分词器逐细胞决定哪些基因共享一个词元时，固定预算能够在不损失注释准确率的情况下覆盖每个转录组的更多部分。

## Abstract
Single-cell foundation models typically treat each gene as a token, which is both costly and wasteful. A cell can express thousands of genes, so one token per gene makes self-attention expensive, yet many of these genes are detected at low levels and carry too little signal to deserve a token of their own. Genes that are expressed together could instead share a token, leaving separate tokens for genes that stand out. We introduce scTAT (Transcriptome-Aware Tokenization), which pairs a gene-set vocabulary with a per-cell tokenizer. The vocabulary holds overlapping gene sets that recur with stable relative expression across the pretraining corpus. Using these sets raises two difficulties. First, which genes should share a token depends on the cell, whereas existing multi-gene tokens fix the grouping in advance. Second, gene sets of different sizes must be compared with single genes on a common scale. The tokenizer therefore decides per cell, letting gene sets and single genes compete for token positions under an expression score normalized by the square root of set size. Training still reconstructs individual genes, so predictions stay at gene resolution. In frozen-embedding cell-type annotation, scTAT matches the strongest one-gene-per-token model with half the token budget. Its advantage over one-gene-per-token models at the same budget grows as the budget shrinks and the tokenizer assigns more positions to gene sets. Encoding the same genes with gene-set tokens also nearly halves the Transformer's matrix-multiplication cost. These results show that a token need not hold exactly one gene: when the tokenizer decides per cell which genes share a token, a fixed budget covers more of each transcriptome at no cost in annotation accuracy.

## 1. 核心问题与整体含义

- **背景**：单细胞基础模型（scGPT、Geneformer、scBERT 等）沿用语言模型范式，把一个细胞写成基因 token 序列，用 Transformer 学习掩码或排序表达。
- **核心矛盾**：在“一基因一 token”下，token 同时决定“模型能看到细胞的多少”和“编码成本”，二者方向相反：
  - 细胞可表达数千基因，而自注意力成本随序列长度呈 O(N²) 增长；
  - 现有模型只能保留基因子集（表达加权采样也只是缓解），大量低表达基因单独占位却信号微弱，属于“昂贵且浪费”。
- **已有缓解方案及其缺陷**：TOSICA（通路/调控子）、Stack（学习基因模块投影）、scREBOUND（蛋白先验软分配）等把多基因打包成一个 token，但**分组在见到任何细胞之前就已固定**，导致：
  - 分组未编码的关系在输入端丢失（通路外基因进不了 token，跨组共变基因无法共享 token）；
  - 哪些基因应共享 token 依赖细胞类型与状态（细胞周期基因、干扰素刺激基因共升，而胰岛 β 细胞的胰岛素等标志基因需单独成 token），固定分组会为细胞不执行的程序浪费位置，并模糊标志基因。
- **整体含义**：论文主张“一个 token 不必恰好装一个基因”，把 token 的内容变成**逐细胞决策**的设计变量，从而在固定预算下覆盖更多转录组，且不牺牲注释精度。

## 2. 方法论（scTAT）

### 2.1 核心思想
- 三件套：**离线挖掘的重叠基因集词表** + **逐细胞 tokenizer**（基因集与单基因竞争位置）+ **仍在单基因空间做重建**的训练目标。
- 词表条目跨细胞共享（基因身份集合），token 是条目在某细胞中的实例（携带该细胞表达）。

### 2.2 词表构建（离线）
- **候选生成**：用预训练 scGPT 的基因嵌入构建 mutual 32-NN 基因图（60,694 基因、202,582 条边）；仅使用图结构，不用 scGPT 权重初始化模型。每个候选集限制在锚点基因的邻域 {a}∪N(a) 内，保证组合搜索可行。
- **MDL 启发的准入分数**（Krimp 式压缩思想）：
  - F(S) = n_S·(Σ_{g∈S} ℓ_g − ℓ_S) − L_desc(S) − n_S·R(S)
  - 第一项：把 S 作为一个单元编码所节省的码长（成员共现频率高于各自频率时为大）；
  - 第二项：描述集合大小与成员的开销；
  - 第三项：稳定性/连通性惩罚 R(S) = D(S) + (1−H(S))/2，D 为支持细胞内集合内表达比例的 Jensen–Shannon 散度，H 为最大生成树平均边权。
- **支持约束**：在 50,000 个训练细胞的**两个不相交发现子集**中各需 ≥50 个支持细胞；贪心扩展直到分数不再提升。
- **规模**：79,536 个基因集（2–32 个基因，中位 4）+ 60,694 个单基因 + 3 个特殊 token。

### 2.3 逐细胞 tokenizer
- 候选资格：基因集需其**全部成员在该细胞中活跃**（S ⊆ A(x)）；每个活跃基因也作为单基因候选。
- 打分（C 为已覆盖基因集合）：
  - Δx(S|C) = Σ_{g∈S\C} x_g（新增覆盖的表达）
  - **s(S|C) = Δx(S|C) / √n_C(S)**，n_C(S) 为新增基因数
- **为何用平方根**：不归一化会偏向大集合；除以 n_C 则等价于平均表达，基因集永远赢不过其最强单基因；√ 居中——新成员共同高表达时集合胜出，某基因独占优势时单基因胜出。
- 流程：每步选最高分条目、更新 C、重算分数；无新基因的条目跳过；平局偏向单基因；预算满或全部活跃基因被覆盖即停。

### 2.4 编码与重建
- token 特征：t_S = Normalize(b_S + φ(v_S) + c_S)，b_S 为成员基因嵌入均值，v_S 为未掩码成员平均表达，φ 为有界标量编码器，c_S 编码掩码比例与条目大小；掩码在基因的所有出现间共享。
- 重建目标始终是**单个基因**：对含基因 g 的 token 输出取平均 r_g 经投影与基因 query 解码（MLM，仅覆盖被 token 覆盖的掩码基因）；另用 CLS 嵌入 + 基因 query 预测所有目标（MVC，含未覆盖基因）；两个平方误差目标联合优化，下游用冻结 CLS 嵌入。

## 8. 启示与可延伸方向

- **把 token 当作设计变量**：论文最有价值的不是某个具体模块，而是提出“token 内容 = 逐细胞决策”这一问题设定，为单细胞基础模型的输入层设计打开了一个此前被默认锁死的维度。
- **压缩视角的迁移**：MDL/Krimp 式准入分数可推广到其他“多实体打包为一 token”的场景（如多组学、空间邻域、扰动组合）。

- **动态/可学习分组**：将 tokenizer 的选择策略做成可微或强化学习模块，使分组随训练信号演化，是对“离线固定词表”这一局限的自然回应。
- **缩放与跨模态**：在更大骨干、更多细胞类型、以及多模态（RNA+ATAC、RNA+蛋白）输入上验证 token 打包的收益边界。

## 9. 总体评价

论文针对单细胞基础模型中“一基因一 token”这一被广泛接受但少被质疑的默认设定，提出了一个清晰的问题重述：token 同时承载“可见性”与“成本”，二者冲突，而固定分组方案只是把冲突挪了位置。scTAT 的解法在工程上克制（离线词表 + 轻量 tokenizer + 单基因重建目标），在概念上统一（基因集与单基因在同一打分尺度竞争），并以“同架构单基因对照”这一干净的实验设计隔离出 token 设计的独立贡献。主要短板在于对外部嵌入的依赖、模型规模偏小、以及端到端成本与生物学验证的深度不足。总体而言，这是一篇**问题意识强于工程炫技、实验设计较严谨**的工作，其核心贡献更可能体现为对后续输入层设计的启发，而非一个终局方案。
