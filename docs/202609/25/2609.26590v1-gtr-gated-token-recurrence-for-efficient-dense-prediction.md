evidence: 面向高效密集预测的递归视觉骨干
tldr: 自注意力视觉骨干在密集预测上表现优异，但全局 softmax 注意力的二次计算成本限制了高分辨率下的效率。GTR 提出无 softmax 的循环视觉骨干，融合门控线性注意力、交替空间扫描方向与空间增强 SwiGLU 模块。它仅用最终层 patch-token 对齐从检测专用 DINOv3 教师蒸馏，无需掩码 token 预测或中间层监督。在 Objects365 检测预训练下，GTR-L 于 COCO val2017 取得 58.9 box AP，RTX 4090 编译 FP16 单批中位延迟 1.908 ms；专用 CUDA 算子较 FLA v0.5.0 快 4.0 倍，TensorRT 在 DRIVE AGX Thor 上延迟 2.282–8.769 ms。该工作表明循环 token 混合可作为高分辨率密集预测与边缘部署的高效替代方案，并迁移至分割、姿态、旋转检测、语义分割和单目深度等任务。

## 摘要
基于自注意力的视觉骨干网络在密集预测上表现良好，但全局 softmax 注意力的二次计算成本限制了其随图像分辨率提高时的效率。我们提出门控 Token 递归（Gated Token Recurrence, GTR），一种无 softmax 的递归视觉骨干网络，它结合了门控线性注意力、交替空间扫描方向和空间增强的 SwiGLU 模块。GTR 从检测专用的 DINOv3 教师模型蒸馏而来，仅通过线性投影和平方 $\ell_2$ 损失进行最终层 patch-token 对齐，不使用掩码 token 预测或中间层监督。在 Objects365 检测器预训练下，GTR-L 在 COCO \texttt{val2017} 上达到 58.9 box AP，在 RTX~4090 上以编译后的 FP16 执行时，中位单批延迟为 1.908 ms。同一骨干网络还可迁移到实例分割、姿态估计、有向目标检测、语义分割和单目深度估计。在孤立内核基准测试中，我们的专用 chunkwise CUDA 算子在 RTX~4090 上处理 1.6K tokens 时比 FLA v0.5.0 快 $4.0\times$。在 DRIVE AGX Thor 上进行 TensorRT 部署时，所评估模型的中位单批延迟为 2.282--8.769 ms。这些结果表明，递归 token 混合可为高分辨率密集预测和边缘部署提供一种高效的全局 softmax 注意力替代方案。项目页面：https://intellindust-ai-lab.github.io/projects/GTR/

## Abstract
Self-attention-based vision backbones perform well on dense prediction, but the quadratic computational cost of global softmax attention limits their efficiency as image resolution increases. We introduce Gated Token Recurrence (GTR), a softmax-free recurrent vision backbone that combines gated linear attention, alternating spatial scan directions, and spatially enhanced SwiGLU blocks. GTR is distilled from a detection-specialized DINOv3 teacher using only final-layer patch-token alignment through a linear projection and squared $\ell_2$ loss, without masked-token prediction or intermediate-layer supervision. With Objects365 detector pre-training, GTR-L achieves 58.9 box AP on COCO \texttt{val2017} with 1.908\,ms median batch-one latency under compiled FP16 execution on an RTX~4090. The same backbone also transfers to instance segmentation, pose estimation, oriented detection, semantic segmentation, and monocular depth estimation. In an isolated kernel benchmark, our specialized chunkwise CUDA operator is $4.0\times$ faster than FLA v0.5.0 at 1.6K tokens on RTX~4090. TensorRT deployment on DRIVE AGX Thor achieves 2.282--8.769\,ms median batch-one latency across the evaluated models. These results show that recurrent token mixing can provide an efficient alternative to global softmax attention for high-resolution dense prediction and edge deployment.Project page: https://intellindust-ai-lab.github.io/projects/GTR/

- **已有尝试**：EfficientViT 探索了端侧语义分割；ViG 将门控线性递归用于检测与分割。但**缺乏一个既能跨多种密集预测任务保持一致精度、又能真正把线性复杂度的理论优势转化为边缘硬件实测收益的通用骨干**。
- **核心研究问题**：线性注意力能否支撑一个通用视觉骨干，在多样密集预测任务上保持精度，并在边缘硬件上实现实用的效率增益？
- **整体含义**：作者提出 GTR，论证了"递归 token 混合"可作为全局 softmax 注意力之外的高效替代路线，兼具精度、速度与部署可行性。

## 2. 方法论

### 2.1 核心思想

GTR 是一个**单尺度、无 softmax 的线性复杂度递归视觉骨干**，由三个组件构成，在 12 个 block 中统一使用：

1. **门控递归（GLA）**——提供长程上下文；
2. **方向性扫描**——建模二维空间上下文；
3. **空间 SwiGLU（Spatial SwiGLU）**——提供显式局部空间混合。

### 2.2 关键技术细节

- **仅 Key 侧门控递归（Key-only GLA）**：
  - 每个 head 维护递归状态 $S_t \in \mathbb{R}^{d_k \times d_v}$，更新为 $S_t = \mathrm{Diag}(\gamma_t)S_{t-1} + k_t^\top v_t$，输出 $o_t = d_k^{-1/2} q_t S_t$，$S_0 = 0$。
  - $\gamma_t = \sigma(x_t W^{(1)}_\alpha W^{(2)}_\alpha + b_\alpha)^{1/\tau}$ 为**学习到的 key 侧保留门**（低秩投影，秩 $r=16$，温度 $\tau=16$）。
  - **Value 侧衰减固定为 1**（训练与推理一致），仅保留 key 侧状态衰减。
  - 额外引入**数据相关输出门** $r_t = \mathrm{SiLU}(x_t W_r)$，$u_t = r_t \odot \mathrm{RMSNorm}(o_t)$，与状态保留门 $\gamma_t$ 不同。
- **方向性扫描**：递归沿扫描顺序是因果的，单一方向只能捕获一个方向的上下文。GTR 在相邻 block 间循环四种扫描方向（左→右、右→左、上→下、下→上），每 block 只做一次扫描并恢复原空间顺序，跨深度逐步聚合互补全局上下文。
- **空间 SwiGLU**（公式 1）：
  $$Y = \big[\mathrm{SiLU}(XW_g) \odot \mathrm{DWConv}_{3\times3}(XW_v)\big] W_o$$
  value 分支 reshape 回二维 patch 网格，经 $3\times3$ 深度卷积后再展平，提供**非因果的邻域局部交互**；门控分支保持 token 级。**GTR 不使用显式位置编码**。
- **复杂度**：递归更新每 head $O(L d_k d_v)$，状态尺寸与 $L$ 无关（常数），激活与工作区显存随 $L$ 线性增长。

### 2.3 蒸馏策略

- 使用检测专用 DINOv3（经 EdgeCrafter 适配）作为**冻结教师**，师生接收同一整图。
- **仅监督最终层 patch token**，用线性投影 $\phi:\mathbb{R}^{d_s}\to\mathbb{R}^{d_t}$ 后接平方 $\ell_2$ 损失：
  $$\mathcal{L}_{\text{align}} = \frac{1}{L}\sum_{i=1}^{L}\|\phi(Y^i_{stu}) - Y^i_{tea}\|_2^2$$
- **无掩码、无中间层监督、无 attention 对齐**，只优化 GTR 与投影层。

### 2.4 硬件感知的 Chunkwise 推理

- 三阶段流程：①并行计算 chunk 摘要 $U_c$；②轻量顺序传播边界状态 $S[c]$；③各 chunk 独立计算输出。
- 公式（3）给出 chunk 摘要与边界状态更新：$\hat{k}_{c,r}=k_{c,r}\odot\exp(A_{c,C_c-1}-A_{c,r})$，$U_c=\sum_r \hat{k}^\top_{c,r} v_{c,r}$，$S[c+1]=\mathrm{Diag}(d_c)S[c]+U_c$。
- 输出核融合 chunk 内计算与边界状态读出。
- 专用配置：FP16 输入、chunk size $C=64$、$d_k=32$、$d_v=64$、零初始状态；训练仍用 FLA 参考核。
- 采用**长度感知调度**：短序列用 fallback 输出核，非波对齐网格用占用感知融合核；支持持久化 workspace、预分配输出缓冲、CUDA Graph 捕获；端到端实现中进一步将 RMSNorm 与输出门融合进 GLA 核。

## 6. 主要结论与发现

- **检测性能**：Objects365 预训练下，GTR-S/M/L/X 分别达 53.6/57.3/58.9/59.4 AP，在四个尺度组中均为最高 AP；GTR-L 以 1.908 ms 中位延迟取得 58.9 AP，同时优于所有 L 尺度基线的精度与延迟；GTR-X 达 59.4 AP @ 2.115 ms，对比 RF-DETR-X 的 58.6 AP @ 3.243 ms。
- **跨任务迁移**：同一骨干设计迁移至实例分割（GTR-X 49.8 mask AP，比 RF-DETR-Seg-X 延迟低 25.3%）、姿态估计（70.1/75.5 AP）、有向检测（81.3 AP50）、语义分割（81.5/83.6 mIoU）、单目深度（各尺度均优于对应 YOLO26-depth，且 FLOPs 更少）。
- **蒸馏结论**：仅最终输出 $\ell_2$ 对齐（50.7 AP）优于 ViT-Linearizer（50.0）与 ViT-AdaLA（48.2），从零训练仅 31.1 AP，说明简单最终输出对齐已足够有效。
- **空间建模结论**：S-SwiGLU 相比学习位置编码提升 1.2/1.3 AP（768²/1024²），额外 FLOPs 极少；四方向扫描（55.5 AP）优于双向（55.0–55.1）与单向（54.4）；单向扫描下若去掉 S-SwiGLU，AP 骤降至 45.6。
- **混合注意力结论**：在 12 个 block 中用 3 个 softmax 注意力替换 GLA，精度几乎无提升（55.4–55.6 vs 55.5 AP），但延迟从 1.908 升至 2.094–2.117 ms、FLOPs 从 106 增至 119，说明纯 GLA 同构设计更优。
- **分辨率缩放**：640²→1280² 时 AP 从 53.6 升至 57.0（小目标 +6.0 AP），token 数增加 4 倍而延迟仅增长 2.06 倍。
- **内核效率**：自定义 chunkwise CUDA 算子在 256/1.6K/16.4K tokens 下分别比 FLA v0.5.0 快 2.6×/4.0×/6.4×。
- **边缘部署**：DRIVE AGX Thor 上 batch=1 延迟 2.282–8.769 ms，与 FP32 PyTorch 参考余弦相似度 ≥0.9989；
