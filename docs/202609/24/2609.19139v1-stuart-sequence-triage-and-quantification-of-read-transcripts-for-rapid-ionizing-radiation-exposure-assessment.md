## 摘要
在电离辐射暴露后，快速医学分诊对应急管理至关重要，但传统的基于比对的生物信息学方法计算量过大，难以适用于大规模伤亡场景。为解决这一问题，我们开发了STUART（读段转录本的序列分诊与定量），这是一个针对移动式生物剂量学优化的无需比对的机器学习框架。受自然语言处理（NLP）启发，该系统将原始测序读段转换为基于k-mer的数值特征谱，完全绕过标准比对。尽管该架构可普遍适用于任何转录组生物标志物，本研究聚焦于使用FDXR基因模型的辐射暴露。通过评估逻辑回归、随机森林和XGBoost，先进的签名选择策略将初始1024维特征空间大幅减少超过98%。在仅保留17个转录组特征签名的情况下，仍持续获得高度稳健的性能——其特点是近乎完美的平衡准确率和处于95–100%范围内的F1分数。关键的是，学习曲线分析表明，完整的信号稳定仅需聚合1000条可能相关的读段。此外，在独立数据集上的外部验证获得了超过99%的特异性，证实了所提取特征签名的组织无关性，尽管细胞来源不同。该框架极低的数据阈值支持与便携式测序仪兼容的实时、边测序边分析诊断范式。通过最小化决策时间，这一去中心化工具弥合了先进生物标志物与实际现场生物监测之间的差距，为快速流行病学响应和常规职业辐射监测提供了可扩展的基础。

## Abstract
Rapid medical triage following ionizing radiation exposure is critical for emergency management, yet traditional alignment-based bioinformatics are too computationally intensive for mass-casualty scenarios. To address this, we developed STUART (Sequence Triage and qUAntification of Read Transcripts), a mapping-free machine learning framework optimized for mobile biological dosimetry. Inspired by Natural Language Processing (NLP), the system converts raw sequencing reads into k-mer-based numerical profiles, completely bypassing standard alignment. While the architecture is universally applicable to any transcriptomic biomarker, this study focused on radiation exposure using the FDXR gene model. Evaluating Logistic Regression, Random Forest, and XGBoost, advanced signature selection strategies drastically reduced the initial 1024-dimensional feature space by over 98%. Highly robust performance - characterized by near-perfect balanced accuracy and F1-scores within the 95-100% range - was consistently achieved while retaining as few as 17 transcriptomic signatures. Crucially, learning curve analysis demonstrated that complete signal stabilization requires aggregating merely 1000 potentially related reads. Furthermore, external validation on an independent dataset yielded over 99% specificity, confirming the tissue-agnostic nature of the extracted signatures despite different cellular origins. The framework's exceptionally low data threshold enables a real-time, analyze-as-you-sequence diagnostic paradigm compatible with portable sequencers. By minimizing time-to-decision, this decentralized tool bridges the gap between advanced biomarkers and practical on-site biomonitoring, offering a scalable foundation for rapid epidemiological response and routine occupational radiation monitoring.

## 2. 方法论

### 2.1 核心思想
- 完全绕过序列比对，将原始测序 reads 转化为 **k-mer 数值特征谱（NLP-profile）**，用词袋模型（Bag of Words, BoW）表示。
- 两阶段流水线：**过滤模块（gating model）** + **暴露评估模块（target predictor）**。

### 2.2 关键技术与流程

- **序列编码（Sequence Encoder）**：
  - 采用 5-letter k-mer（中心 3-letter NLP-type word 加上下文间隔 1 的前后核苷酸，数学上等价于 5-mer）。
  - 统计 k-mer 出现次数，形成 BoW 数值向量，即 NLP-profile。
  - 字典维度基础为 4^5 = **1024** 维。

- **门控模型（Gating Model）**：
  - 使用作者此前开发的 **noMapper** 工具，将 NLP-profile 分类为“可能与生物标志物相关”与“其他”两类。
  - 基于三种字典（Complete 1024 / OR-driven 156 / XAI-driven 77）训练三个独立门控模型，产生不同的“可能相关”序列池。

- **指纹构建（Fingerprint Construction）**：
  1. **聚合**：对 f 个随机选取的 NLP-profile 的 BoW 向量求和。
  2. **L1 归一化**：转化为 NLP-type word 的相对频率分布。
  3. **维度缩放**：乘以 √d（d=1024/156/77），校正 L1 归一化对信号的“稀释”。
  4. **基线扣除**：减去各自队列的对照指纹均值，以隔离辐射诱导信号。

- **目标预测器（Target Predictors）**：
  - **Logistic Regression (LR)**：线性基线模型。
  - **Random Forest (RF)**：装袋式决策树集成，多数投票。
  - **XGBoost (XGB)**：梯度提升树，顺序纠错。

- **签名选择（Signature Selection）**：
  - **LR**：BF-guided Forward Selection（前向特征选择），以基于 BIC 的 Bayes Factor > 20 作为停止准则。
  - **RF/XGB**：采用 **Permutation Importance (PI)**（而非 Gini/Gain，以减少偏差），并用 **Piecewise Linear Regression (PLR)** 对重要性排序拟合两段线性，以残差平方和最小化确定最优签名数（top-N）的天然截断点。

- **三种建模方案**：LR-based、RF-based、XGB-based，各自结合对应的签名选择策略。

## 6. 主要结论与发现

- **维度大幅压缩**：签名选择使初始 1024 维特征空间缩减 **超过 98%**，最优结果仅需 **17 个转录组签名**（OR-driven 空间）。
- **性能优异且对称**：在保留 17 个签名时，BACC 与 F1 稳定在 **95%–100%** 区间，NPV/PPV 平衡，无明显类别偏向。
- **过度压缩的风险**：XAI-driven Reduced FT（仅 5 个签名）导致 BACC 与 NPV 骤降至约 55%，置信区间显著变宽，说明特征空间过度缩减会严重损害稳定性。
- **算法共识**：OR-driven 空间中，三种数学架构不同的模型**独立选出 14 个共享签名**，表明捕获的是真实生物学响应而非算法伪影。
- **极低数据阈值**：学习曲线显示 f ≈ 250 时性能低（~75%）且不稳定，**f = 1000** 时信号完全稳定，此后曲线进入平台期。
- **组织无关性**：外部 SG-NEx（HepG2 肝癌细胞）验证中，所有 FT 变体 SPEC **超过 99.7%**，证明签名消除了组织特异性偏差。
- **应用价值**：支持“边测序边分析”，累积 1000 条相关 reads 即可触发预测，最小化决策时间，兼容便携式测序仪。

## 7. 优点

- **范式创新**：将 NLP 的 k-mer/BoW 思路与生物剂量学结合，完全绕过比对，显著降低计算负载。
- **通用架构**：明确声明分析流程可推广至任意转录组标志物，FDXR 仅为验证模型，具有可扩展性。
- **严格的防泄漏设计**：在数据点生成前按样本划分训练/测试集，避免数据泄漏。
- **稳健的特征选择策略**：
  - LR 使用 BF 作为统计停止准则，避免过拟合。
  - RF/XGB 使用 Permutation Importance 而非有偏的 Gini/Gain，并用 PLR 客观确定截断点。
- **多模型交叉验证**：线性模型与树模型并行，并通过 Venn 图证明签名选择的算法无关性，增强结论可信度。
- **外部独立验证**：在完全不同的细胞系上验证，证明签名的组织无关性与抗过拟合能力。
- **实用导向**：低数据阈值与轻量化设计直接支撑现场部署与实时分诊。
