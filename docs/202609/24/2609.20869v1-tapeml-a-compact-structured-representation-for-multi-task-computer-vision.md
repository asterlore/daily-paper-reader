## 摘要
我们提出 TAPe+ML v3，一个基于 TAPe（主动感知理论）的紧凑计算机视觉系统。TAPe 是一种结构化表示，在识别之前编码感知元素之间的关系。该系统不直接作用于像素张量，而是使用共享的 TAPe 表示和模块化识别架构，用于图像分类、目标检测和实例分割。TAPe+ML v3 结合了背景与轮廓处理、局部目标定位、基于原型的分类，以及用于专门子模型的协调器。在所报告的实验中，它使用了少于 100,000 个参数。在 COCO 目标检测上，它获得 84.7 mAP50 和 65.3 mAP50-95。在 COCO 实例分割上，它获得 80.7 mask mAP50 和 58.4 mask mAP50-95。在分类实验中，在与原始像素基线进行相同训练比较的情况下，它在 Imagenette 上达到 92% 的验证准确率，并在 ImageNet-Real 上达到 89.9% 的 Top-1 准确率。我们还在工业试点中评估了视频场景检测中的紧凑性以及分布偏移下的适应性。结果表明，将部分建模负担从网络参数转移到结构化输入表示，可以支持具有更少数据、内存和计算需求的紧凑多任务视觉系统。

## Abstract
We present TAPe+ML v3, a compact computer vision system based on TAPe (Theory of Active Perception), a structured representation that encodes relations among perceptual elements before recognition. Instead of operating directly on pixel tensors, the system uses a shared TAPe representation and a modular recognition architecture for image classification, object detection, and instance segmentation.   TAPe+ML v3 combines background and contour processing, local object localization, prototype-based classification, and a coordinator for specialized submodels. Across the reported experiments, it uses fewer than 100,000 parameters. On COCO object detection, it obtains 84.7 mAP50 and 65.3 mAP50-95. On COCO instance segmentation, it obtains 80.7 mask mAP50 and 58.4 mask mAP50-95. In classification experiments, it reaches 92 percent validation accuracy on Imagenette under an identical-training comparison with a raw-pixel baseline, and 89.9 percent Top-1 accuracy on ImageNet-Real. We also evaluate compactness in video scene detection and adaptation under distribution shift in an industrial pilot. The results suggest that shifting part of the modeling burden from network parameters to a structured input representation can support compact multi-task vision systems with reduced data, memory, and compute requirements.

- **数据与标注成本**：像素表示不稳定，DINOv2 等模型需上亿图像；TAPe 论文认为结构化表示可显著降低对样本量的依赖。

- **核心主张**：性能提升不必只靠扩大参数与预训练，也可通过更信息化的输入表示和模块化协调来实现。

## 2. 方法论
- **核心思想**：用 TAPe 表示替代原始像素或常规 patch。图像被映射为结构化关系图：  
  \( I \mapsto G(I)=(\{t_1,\dots,t_k\}, E) \)  
  其中 \(t_i\) 为 T-bit，\(E\) 为 T-bit 间连接关系。
- **T-bit 定义**：T-bit 是最有信息量、相互关联的信息元素子集，不是单个像素；它已编码元素间关系，因而更利于识别。
- **TAPe 属性**：
  - 对局部变换、光照变化、轻微形变和噪声更稳定。
  - 同一场景不同帧的 TAPe 索引近似，语义稳定性强。
  - 索引紧凑，可直接用于相似度搜索，距离对应语义距离。
- **TAPe+ML v3 架构**：
  - **背景模型**：以 Bag of Words 形式接收 TAPe，区分背景/非背景，生成几何 mask、轮廓和样条曲线。
  - **指针模型**：定位候选对象区域，使用 TAPe patch 局部关联，替代 Transformer 全局注意力。
  - **原型聚类模型**：用 k-means 在 TAPe 空间形成类原型，推理时匹配原型，分类不依赖梯度下降和独立线性分类头。
  - **子模型协调器**：控制背景、指针、原型模型的调用顺序，组合为检测、分类、分割输出；可按数据集复杂度自动扩展子模型数量。
- **分割机制**：
  - 三阶段：边界检测 → 折线合并为多边形 → 内部面合并，减少碎片段。
  - 使用布尔操作构造 mask，保证拓扑正确，只在真实孔洞处留洞。
  - 训练时各中间层有辅助头，推理时只保留最终轮廓输出。
- **训练与适应模式**：
  - **Head-only**：冻结骨干，仅训练任务头，适合域内任务。
  - **Backbone adaptation**：同时调整骨干和头，适合 OOD 任务。
  - **From-scratch**：完全重训，适合全新域。
  - **Auto-annotate**：标注 10–15 张后自动扩展标注，人工审核修正。
- **无梯度分类**：分类组件用 k-means/坐标下降替代梯度下降，减少学习率依赖；论文称该改动带来约 3 个百分点提升。
- **共享训练目标**：检测与分割共享损失联合优化，检测训练自动带动分割，反之亦然。
