## 摘要
基于语义解析（SP）的知识库问答旨在通过生成可在知识库（KB）上执行的逻辑形式（LF）来回答自然语言问题。将大语言模型（LLM）应用于该任务时，在大型异构知识库上，一个关键挑战是选择与问题相关的模式元素（即关系和类）并将它们组合成复杂的逻辑形式。近期基于 LLM 的方法在中间推理过程中往往过早地对模式元素做出离散确定，使得错误的中间模式决策得以传播，最终导致错误的逻辑形式。为克服这一局限，我们提出 SALR，一种用于逻辑形式构建的模式锚定潜在推理方法。它通过在模型隐藏状态中生成连续思维来执行多步推理，从而延迟对逻辑形式决策的显式确定。为了将该潜在推理过程锚定到相应的知识库模式，SALR 通过一个由从金标准逻辑形式确定性推导出的模式轨迹所监督的对齐目标，将连续思维与知识库模式元素的码本对齐。然后，它将对齐后的模式编码并入后续推理步骤的输入。这种以模式为中介的反馈引导逻辑形式生成，而无需模型输出显式的文本推理轨迹。在 GrailQA 和 WebQSP 上的实验表明，SALR 相较强基线取得了持续的总体提升。值得注意的是，在 GrailQA 的组合型问题上，SALR 比强 SP 基线 TIARA 高出 2.86 个 F1 点。进一步分析表明，模式中介反馈会影响逻辑形式生成，并且模式信息可从潜在状态中恢复。

## Abstract
Semantic parsing (SP)-based knowledge base question answering aims to answer natural language questions by generating executable logical forms (LFs) over knowledge bases (KBs). When applying Large Language Models (LLMs) to this task, a key challenge over large, heterogeneous KBs is selecting question-related schema elements (i.e., relations and classes) and composing them into complex LFs. Recent LLM-based methods often make early discrete commitments to schema elements during intermediate reasoning, allowing incorrect intermediate schema decisions to propagate and finally result in incorrect LFs. To overcome this limitation, we propose SALR, a schema-anchored latent reasoning method for LF construction. It performs multi-step reasoning by generating continuous thoughts in the model's hidden states, thereby delaying the explicit commitment to LF decisions. To ground this latent reasoning process in the corresponding KB schema, SALR aligns continuous thoughts with a codebook of KB schema elements through an alignment objective supervised by schema traces deterministically derived from gold LFs. It then incorporates the aligned schema codes into inputs for subsequent reasoning steps. This schema-mediated feedback guides LF generation without requiring the model to emit an explicit textual reasoning trajectory. Experiments on GrailQA and WebQSP show that SALR achieves consistent overall gains over strong baselines. Notably, on compositional questions from GrailQA, SALR outperforms TIARA, a strong SP-based baseline, by 2.86 F1 points. Further analyses show that schema-mediated feedback affects LF generation and that schema information is recoverable from the latent states.

## 1. 核心问题与整体含义

- **研究背景**：基于语义解析（SP）的知识库问答（KBQA）将自然语言问题映射为可在知识库（如 Freebase、DBpedia、Wikidata）上执行的逻辑形式（LF），再执行得到答案，具有可执行、可验证、结构化对齐的优势。
- **核心痛点**：将 LLM 用于 SP-based KBQA 时，在大型异构知识库上需要选择与问题相关的模式元素（关系 relations 与类 classes）并组合成复杂 LF。现有方法常将模式组合外化为文本推理链，在中间步骤**过早地离散确定**关系/类/部分 LF，导致错误中间决策沿生成过程传播至最终 LF。
- **实证支撑**：论文对 TIARA 在 GrailQA 验证集上的分析显示，在包含至少一个错误中间模式预测的多步样本中，**74.1% 的首次错误发生在第一步**，且这些样本中 **99.2% 最终生成错误 LF**——说明显式文本模式错误极少能在最终生成阶段被挽回。
- **整体含义**：论文提出 **SALR**，在连续隐空间中进行多步推理以延迟离散承诺，同时用知识库模式结构锚定连续思维，从而兼顾"延迟承诺"与"任务特定结构约束"，为 SP-based KBQA 提供了一种无需显式文本推理轨迹的新范式。

## 2. 方法论

### 2.1 核心思想
- 在 LF 自回归解码之前，于模型隐藏状态中执行多步**潜在推理**，产生连续思维（continuous thoughts），延迟对完整 LF 的显式承诺。
- 通过 **Schema Anchoring Module** 将每个连续思维与固定的知识库模式码本对齐，并把选中的模式编码转换为"构造思维"（constructed thought）反馈到后续潜在计算，形成**模式中介的潜在反馈环**。

### 2.2 关键技术细节

**(1) 模式轨迹与模式码本**
- 从金标准 LF 确定性推导**模式轨迹**：沿查询图各组合分支遍历，将同一组合深度上的模式元素归为一步，得到 $\tau(l)=(\tau_1,\dots,\tau_T)$，$\tau_t \subseteq S$（$S=R\cup C$ 为有限模式集合）。
- **模式码本**：对每个模式元素 $s$，用任务训练前的 LLM 对文本序列化 $text(s)$ 做末层隐藏状态均值池化，得到连续模式码 $b_s$；码本预计算一次并保持固定。

**(2) Schema Anchoring Module**
- **模式对齐**：用两层 MLP 投影器 $g_\phi$ 将连续思维 $h_t$ 投影为 $z_t$，与正样本码 $b_s$（$s\in\tau_t$）及负样本码做 InfoNCE 式对比学习，损失为 $L_{align}$（温度 0.07，每正样本采 32 个负样本），对 $\tau_t$ 内正样本取平均以支持并行约束。
- **模式选择与潜在构造**：训练时直接查表金标准轨迹子集 $\tau_t$，做均值聚合 $\bar{b}_t$，经两层 MLP $f_\psi$ 得到构造思维 $\hat{h}_t$ 作为下一步潜在输入；均值聚合不引入任意顺序。

**(3) 自适应终止**
- 用线性终止头 $r_\eta$ 对每个连续思维预测停止概率，训练标签为前 $T$ 步 continue、第 $T+1$ 步 stop，损失 $L_{term}$ 为交叉熵。

**(4) 训练目标**
- 总损失 $L = L_{LF} + \lambda_{align}L_{align} + \lambda_{term}L_{term}$，其中 $L_{LF}$ 为以构造思维为条件的 LF 生成负对数似然；$\lambda_{align}=0.2$，$\lambda_{term}=0.1$。
- 与 COCONUT 不同，**无需课程学习**：LF 导出的模式轨迹与终止标签提供了步级监督。

**(5) 推理流程**
- 输入经 `<bot>` 得到 $h_1$；循环内先判断是否停止（$p^{stop}_t>0.5$），否则投影后从码本做 **Top-k（k=3）相似度选择**，均值聚合后构造 $\hat{h}_t$ 作为下一步输入；结束后接 `<eot>` 自回归解码 LF（beam search 10 个候选）。
- 保留多个模式候选并行引导后续计算，而非序列化单个文本决策。执行失败或答案为空时采用检索上下文中的最高分示例 LF 作为回退（execution-based fallback）。

## 6. 主要结论与发现

- **整体提升**：在 GrailQA 上 SALR 使 TIARA 提升 1.51 EM / 1.30 F1，使 SG-KBQA 提升 0.97 EM / 0.51 F1；WebQSP 上分别提升至 76.85 与 79.96 F1。
- **组合型问题增益最大**：GrailQA Compositional 上分别比 TIARA、SG-KBQA 高 **2.86** 和 **2.65 F1**；零样本也有 +1.37 / +1.00 F1 提升；但 I.I.D. F1 分别下降 0.35 与 2.66（作者解释为 I.I.D. 直接解码已很可靠，多候选可能引入干扰）。
- **模式信息可恢复**：SALR 的 R@27 为 33.58、MRR 0.1010，显著优于通用潜在推理 + 事后探针（24.15 / 0.0654），随机检索接近 0。
- **潜在几何差异**：SALR 相邻步相似度更低、各步区域更可区分，而通用潜在推理步间高度相似、呈集中簇。
- **反馈机制确实被使用**：用金标准码替换预测码使 F1 从 85.42 升至 85.85；联合随机化码序列长度与 ID 则降至 71.81，证明模式中介反馈可影响最终 LF。
- **效率**：相比显式文本推理，SALR 将平均解码位置从 62.36 降至 38.51，总计算量相当（5.96 vs 6.00 TFLOPs/例），但比直接解码更贵。
- **骨干迁移**：Qwen3-4B 上仍有一致提升（overall 82.91→83.28，compositional 77.70→78.47）。

## 7. 优点

- **范式创新**：将连续潜在推理与知识库符号模式结构结合，既延迟离散承诺，又保留任务特定结构约束，区别于通用潜在推理（COCONUT 等）。
- **监督信号巧妙**：从金标准 LF 确定性推导步级模式轨迹，为潜在推理提供无需人工标注的步级监督，且**无需课程学习**。
- **即插即用**：可分别与 TIARA、SG-KBQA 两种检索管线组合，并在两个数据集、两个骨干（Llama-3.1-8B、Qwen3-4B）上验证。
- **分析体系完整**：可恢复性探针 + 潜在几何 + 反馈干预 + 案例研究，形成"信息存在—结构合理—被实际使用"的完整证据链，而非仅报告分数。
- **效率可控**：相较显式文本推理减少解码位置，总计算量相当。
- **附录提供信息论视角**：用 InfoNCE 界与数据处理不等式解释 $L_{LF}$ 与 $L_{align}$ 分别对应"构造思维对 LF 的信息量"和"连续思维对模式的可恢复性"，理论支撑较扎实。

## 8. 不足与局限

- **依赖检索质量**：SALR 只聚焦检索后的 LF 构建，不修复缺失的模式证据，性能上限受检索上下文质量约束。
- **假设受限**：需要可枚举的知识库模式集合与金标准 LF 以推导步级轨迹，引入任务特定预处理，难以直接推广到无结构化符号锚点的开放推理场景。
- **可解释性不完整**：探针与干预分析虽提供了接口，但作者明确表示这不构成对潜在推理过程的完整忠实解释。
- **额外推理开销**：潜在计算与模式反馈使其比直接解码更昂贵。
- **I.I.D. 上的下降**：在已见模式与查询结构上反而略有退化，多候选 Top-k 可能引入干扰。
- **实验覆盖**：跨骨干迁移实验仅用 5000 样本子集、单一较小模型（Qwen3-4B），模型家族、规模与知识库的通用性仍需更多验证；未报告训练时长与总计算开销。
- **应用限制**：知识库与 LLM 可能包含不完整、过时或有社会偏见的信息，生成 LF 可能返回错误答案；作者建议在高风险场景下加入答案验证、检索覆盖报告、来源追踪与人工监督，避免将基准整体提升等同于可靠性的均匀提升。
