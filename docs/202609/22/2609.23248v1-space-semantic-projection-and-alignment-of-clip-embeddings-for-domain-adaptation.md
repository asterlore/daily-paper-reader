## 摘要
部署视觉模型的一个基本挑战是域偏移，即训练数据和测试数据服从不同分布时导致性能下降。当同一语义概念以不同的视觉形式出现时，例如照片和素描，尽管语义上对应，但视觉相似性很弱，这一挑战会被放大。现有的无监督域适应方法旨在对齐不同域之间的分布，但往往忽略同类样本之间的语义关系。为了解决这一问题，本文提出 SPACE，一种利用 CLIP 视觉-语言空间的语义结构进行域适应的方法。其核心思想是使用文本描述作为语义锚点，通过对类别描述的 CLIP 嵌入应用奇异值分解，得到一个捕捉类别间语义关系的正交基。来自两个域的视觉特征被投影到这个语义子空间中，从而根据含义而非外观来对齐图像。

## Abstract
A fundamental challenge in deploying vision models is domain shift, which arises when training and test data follow different distributions, leading to degraded performance. This challenge is amplified when the same semantic concept appears under distinct visual forms, such as photographs and sketches, where visual similarity is weak despite semantic correspondence. Existing unsupervised domain-adaptation methods aim to align distributions across domains but often ignore semantic relationships among samples of the same class. To address this issue, this paper introduces SPACE, a method that exploits the semantic structure of CLIP's vision-language space for domain adaptation. The key idea is to use text descriptions as semantic anchors by applying Singular Value Decomposition to CLIP embeddings of class descriptions, yielding an orthogonal basis that captures semantic relationships among categories. Visual features from both domains are projected into this semantic subspace, aligning images based on meaning rather than appearance.

- **整体含义**：论文提出 SPACE，利用 CLIP 视觉-语言嵌入空间的语义结构进行域适应。核心思想是把文本类描述作为语义锚点，通过 SVD 构造正交语义子空间，使图像特征按“语义”而非“外观”对齐，从而把域特定风格剥离到残差中。

## 2. 方法论

- **核心思想**：假设 CLIP 视觉特征同时包含语义内容和域特定风格。SPACE 将特征分解为：
  - 语义分量：投影到由类文本嵌入构造的正交语义子空间；
  - 域特定残差：与语义子空间正交的部分，用于跨域分布对齐。
- **语义子空间构造**：
  - 对每个类别 \(k\) 使用 CLIP 文本编码器 \(f_t(\cdot)\) 生成文本探针：  
    \(t_k = f_t(\text{“a photo of a [class]”})\)，\(t_k \in \mathbb{R}^d\)。
  - 组织为矩阵 \(T=[t_1,\dots,t_K] \in \mathbb{R}^{d\times K}\)，做 SVD：  
    \(T = U\Sigma V^\top\)。
  - 取前 \(r\) 个左奇异向量 \(U_r=[u_1,\dots,u_r]\in\mathbb{R}^{d\times r}\)，构成 \(r\) 维正交语义基；实验中 \(r=K\)，即等于类别数。
- **特征投影与残差分解**：
  - 源/目标图像经 CLIP 视觉编码器得 \(z_i=f_v(x_i)\in\mathbb{R}^d\)。
  - 语义投影：\(p_i = U_r^\top z_i \in \mathbb{R}^r\)。
  - 域特定残差：  
    \(r_i = z_i - U_r p_i = (I - U_r U_r^\top)z_i\)。
- **训练目标**：
  - 类原型：将文本探针投影到子空间，\(q_k = U_r^\top t_k\)。
  - 源域监督损失 \(L_{src}\)：对投影图像特征 \(p_i^s\) 与类原型矩阵 \(Q\) 的余弦相似度做交叉熵。
  - 目标域伪标签损失 \(L_{pseudo}\)：用最近类原型分配伪标签 \(\hat y_i^t = \arg\max_k \mathrm{sim}(p_i^t,q_k)\)，并以置信度阈值 \(\tau\) 过滤低置信样本后做交叉熵。
  - 残差 MMD 损失 \(L_{MMD}\)：对源域与目标域的残差 \(r_i^s,r_i^t\) 做多核 MMD 对齐，核函数为高斯 RBF，映射到 RKHS。
  - 总损失：  
    \(L_{total}=L_{src}+\lambda_p L_{pseudo}+\lambda_m L_{MMD}\)。  
    实验中 \(\lambda_p=0.5\)，\(\lambda_m=0.1\)，\(\tau=0.9\)。
- **训练策略**：冻结 CLIP 文本编码器与视觉编码器初始 block，仅微调视觉编码器最后 block 和投影层；Office-31/Office-Home 用 ResNet-50 视觉骨干，VisDA-2017 用 ResNet-101。
