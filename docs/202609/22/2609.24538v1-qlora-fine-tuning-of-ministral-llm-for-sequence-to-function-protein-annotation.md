## 摘要
对新测序蛋白质的功能注释仍是分子生物学中的瓶颈：公共数据库中的序列数量增长速度远超人工审编能力。大多数计算方法将注释视为在固定本体上的多标签分类，这会将预测限制在预定义标签集内。在本工作中，我们将蛋白质注释研究为序列到文本生成问题。我们在序列-注释对数据上，使用 QLoRA（4 位 NF4 量化与低秩适配器）对 3B 参数的 Ministral 3 基础模型进行微调。我们采用 LLM-as-expert 协议评估预测：将一个 GPT 模型提示为资深分子生物学审编员，对生物体识别进行二分类评分，并评估功能注释质量。我们得出结论：经 QLoRA 微调的紧凑 LLM 能够为相当一部分蛋白质生成具有真正生物学价值的审编员风格注释。我们还讨论了数据质量、模型扩展和证据支撑方面的未来方向，这些方向是使该方法足够可靠以供实际使用所必需的。

## Abstract
Functional annotation of newly sequenced proteins remains a bottleneck in molecular biology: the number of sequences in public repositories grows far faster than the capacity for manual curation. Most computational approaches consider annotation as multi-label classification over a fixed ontology, which constrains predictions to a predefined label set. In this work we study the the protein annotation as a sequence-to-text generation problem. We fine-tune the 3B-parameter Ministral 3 base model with QLoRA (4-bit NF4 quantization with low-rank adapters) on sequence annotation pairs. We assess predictions with an LLM-as-expert protocol: a GPT model prompted as a senior molecular-biology curator scores organism identification as binary and function annotation quality. We conclude that QLoRA-fine-tuned compact LLMs can generate curator-style annotations with genuine biological value for a substantial subset of proteins. We also discuss future directions in data quality, model scaling, and evidence grounding that are needed to make the approach sufficiently reliable for practical use.

## 2. 方法论

### 2.1 核心思想

- 将蛋白质功能注释视为条件文本生成：给定氨基酸序列，生成一个 JSON 对象，包含来源物种和 UniProt 风格 FUNCTION 描述。
- 使用 **QLoRA** 对 3B 参数的 Ministral 3 基础模型进行 4-bit 量化微调，仅训练低秩适配器。
- 用 **LLM-as-expert** 协议评估生成文本的生物学正确性，而非表面 n-gram 重叠。

### 2.2 数据构造与目标格式

- 从 UniProtKB/Swiss-Prot 检索人工审编条目，查询条件为 `reviewed:true AND length:[50 TO 1024]`，检索 350,000 条。
- 过滤规则：
  - 仅保留在语料中出现至少 500 次的物种，得到 34 个物种；
  - 序列长度 ≤ 700 残基，功能注释长度 ≤ 850 字符；
  - 去除重复序列、含非标准氨基酸符号的序列、以及“uncharacterized / function unknown”目标。
- 最终得到 **72,873 个序列–功能对**；训练/测试随机划分，测试比例 0.03，训练集 67,553，测试集 2,090（评估时实际使用 1,444 个 held-out 蛋白）。
- 监督目标拼接为：`Organism + "; " + Function [CC]`，再包成单键 JSON：`{"function": "..."}`，便于机器解析和确定停止条件。
- 评估时在第一个分号处切分物种与功能部分。

### 2.3 序列表示与提示格式

- 氨基酸序列以空格分隔呈现，如 `"M K A V S P ..."`，避免子词分词器把相邻残基合并成随上下文变化的多字符 token，使残基到 token 的映射近似一对一且位置稳定。
- 序列包裹在 `<protein>` 标签内，整体通过 Mistral 聊天模板渲染为 `<s>[INST] ... [/INST]`。
- 训练序列由 prompt token 与 target token 直接拼接，保证 prompt 是训练序列的精确前缀；损失只在答案 token 上计算，prompt 位置设为 `-100`。
- 最大序列长度 1,536 token。

### 2.4 模型与 QLoRA 配置

- 基础模型：`mistralai/Ministral-3-3B-Base-2512`，4-bit NF4 量化，双重量化，bfloat16 计算，冻结权重约占用 2.6 GB GPU 显存。
- LoRA 注入所有七个投影矩阵：`q_proj, k_proj, v_proj, o_proj, gate_proj, up_proj, down_proj`。
- LoRA 超参：rank `r=64`，`alpha=128`（α/r=2），dropout 0.05，无 bias 训练。
- 可训练参数 **135,004,160 / 3,984,094,208 = 3.39%**。

### 2.5 训练设置

- 3 个 epoch，单张 NVIDIA A100-SXM4-80GB，bf16，TF32 matmul。
- 每设备 batch 16，梯度累积 2，有效 batch 32，共 **6,336 optimizer steps**。
- 学习率 `1e-4`，cosine 调度，1% warmup，paged 8-bit AdamW，梯度检查点，按长度分组批处理，padding 到 8 的倍数。
- 每 300 步在固定 300 例验证子集上计算验证损失并保存 checkpoint。
- 训练时长 **7.18 小时**，吞吐 **7.84 samples/s**。

### 2.6 推理

- 适配器附加到同一 4-bit 基础模型，保证训练与推理的冻结权重一致。
- 使用贪心解码（`do_sample=False`），批大小 16，左 padding，启用 KV cache，生成到 JSON 对象结束的 EOS token。

### 2.7 LLM-as-expert 评估协议

- 使用 GPT API 模型 `gpt-5.6-terra`，系统提示将其设定为资深分子生物学、生物化学、酶学与蛋白质科学专家，熟悉 Swiss-Prot 审编实践。
- 评估前解析参考与预测：在第一个分号处切分物种和功能，去掉 `FUNCTION:` 前缀，移除 UniProt 证据标签（`{ECO:...}`、`(PubMed:...)`、`(By similarity)`）。
- 评分任务：
  - **Task A：organism_predicted ∈ {0,1}**，同一物种为 1；不同物种、仅属名或缺失为 0；忽略格式、俗名、同义词、株系差异。
  - **Task B：function_quality ∈ {0,...,10}**，按分子功能、生物过程/通路、具体细节的重要性加权；10 为生物学等价，0 为完全错误/矛盾/空；模糊的“可能参与”上限为 3；功能独立于物种正确性评分。
  - **Task C：comments**，1–2 句专家评论。
- 使用结构化输出解码，要求先给出 rationale 再给分数；请求并行执行、失败重试、结果缓存，输出 CSV 包含 reference、prediction、organism_predicted、function_quality、comments。
- 报告指标：物种准确率、功能质量均值/中位数、功能质量 ≥7 的比例（视为“可用注释”阈值）。

## 6. 主要结论与发现

- **核心正面结论**：
  - 3B 参数通用模型，仅输入空格分隔的氨基酸序列，训练 3.39% 参数、单 GPU 约 7 小时，即可为一部分蛋白生成专家判定为生物学等价的注释。
  - **12.7%** 的 held-out 预测被判定为与 Swiss-Prot 注释生物学等价（得分 10）。
  - **19.9%** 达到可用质量（得分 ≥7），**17.7%** 得分 ≥8。
  - 物种识别准确率 **40.4%**。
  - 功能质量均值 **2.72/10**，中位数 **1.0**。
  - 物种正确且功能得分 ≥7 的联合成功率 **8.7%**。
- **双峰分布**：
  - 42.6% 预测得分为 0，12.7% 得分为 10；4–6 分仅占 6.9%。
  - 模型要么几乎精确恢复策展功能，要么为不同蛋白生成流畅注释；幻觉而非模糊是主要失败模式。
- **物种与功能弱耦合**：
  - 功能得分为 10 的预测中，物种正确率仅 50.0%；功能得分为 0 的预测中，物种正确率 34.5%。
  - 高保守蛋白可能功能文本正确但物种错误，模型倾向于使用训练分布中占主导的物种先验。
- **证据标签伪造**：
  - 87.0% 的预测带 ECO 标签，参考为 88.2%；31.3% 的预测引用至少一个 PubMed ID。
  - 引用文献的预测中，96.9% 至少引用一个参考中不存在的 PubMed ID；仅 3.5% 与参考共享任一 ID。
  - 即使功能得分为 10 且带引用，80.0% 仍引用至少一个参考中没有的 ID。
  - 说明模型学会的是引用“形式”，而非可推断的事实内容；证据标签应从训练目标中移除，并由外部检索步骤重新附加。
- **错误类型**：
  - 自信误分配（主导）：为不同蛋白家族生成结构完整、看似合理的注释。
  - 无支持的具体化
