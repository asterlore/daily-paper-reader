## 摘要
视觉 Transformer（ViT）在一系列计算机视觉任务中取得了最先进的性能，这主要归功于自注意力机制。然而，其复杂度随 token 数量呈二次增长，仍是 ViT 效率和规模化部署的主要障碍。Token 合并通过聚合冗余 token 来降低这一开销。然而，现有方法通常只在单一架构中进行评估，因此其有效性究竟源于合并机制本身，还是源于与之搭配的特定解码器，仍悬而未决。我们将图引导 Token 合并（Graph-Guided Token Merging, G2TM）——一个在基于 ViT 的网络中早期插入的单一模块——从最初的 Segmenter 设置扩展到其他场景。我们在三种语义分割框架（Segmenter、SETR、EoMT）和三类解码器（线性、基于 Transformer、基于卷积）以及标准 ViT 图像分类上评估 G2TM。结果表明，对于给定的骨干网络规模，G2TM 的行为与精度-效率权衡在所有测试架构中保持一致，这表明其有效性是编码器的属性，而非解码器的属性。G2TM 也能很好地泛化到图像分类，相比语义分割，其精度下降甚至更小。我们进一步发现，G2TM 的最优超参数——在 ADE20K 数据集上使分割模型的 GFLOPs 持续降低 22-47%，吞吐量最高提升 74%——主要取决于骨干网络的预训练方案和目标数据集，而非解码器选择。

## Abstract
Vision Transformers (ViTs) have achieved state-of-the-art performance across a range of computer vision tasks, mainly thanks to the self-attention mechanism. However, its complexity, increasing quadratically with the number of tokens, remains the major obstacle to ViT efficiency and deployment at scale. Token merging reduces this cost by aggregating redundant tokens. Yet existing methods are typically evaluated within a single architecture, leaving open whether their effectiveness stems from the merging mechanism itself or from the specific decoder they are paired with. We extend Graph-Guided Token Merging (G2TM), a single module inserted early in a ViT-based network, beyond its original Segmenter setting. We evaluate G2TM across three semantic segmentation frameworks (Segmenter, SETR, EoMT) and three decoder families (Linear, Transformer-, convolution-based), as well as standard ViT image classification. Our results show that G2TM's behavior and accuracy-efficiency trade-off are consistent across every tested architecture for a given backbone size, indicating that its effectiveness is a property of the encoder rather than the decoder. G2TM also generalizes well to image classification, achieving an even smaller degradation in accuracy compared to semantic segmentation. We further find that G2TM's optimal hyperparameters, resulting in a consistent drop in GFLOPs of 22-47% and an increase in throughput by up to 74% for segmentation models on ADE20K dataset, depend primarily on the backbone's pre-training recipe and on the target dataset, rather than on the decoder choice.

# 论文总结：Decoder-Agnostic Token Merging for Vision Transformers: A Systematic Study of G2TM

## 1. 核心问题与整体含义

- **背景**：视觉 Transformer（ViT）凭借自注意力机制在分类、分割等任务上取得 SOTA，但自注意力复杂度随 token 数量**二次增长**。语义分割等密集预测任务为保留细粒度细节，往往输入高分辨率图像，token 数常超过 1000，成为效率与规模化部署的主要瓶颈。
- **现有方案的局限**：Token 合并（token merging）通过聚合冗余 token 来降本，但既有方法几乎都在**单一网络架构**内评测，导致一个关键问题悬而未决：其有效性究竟来自**合并机制本身**，还是来自与之搭配的**特定解码器**？
- **本文切入点**：以已有的 **Graph-Guided Token Merging（G2TM）** 为对象，把它从最初仅用于 Segmenter 的设定，扩展到三种语义分割框架与三类解码器家族，并进一步用于 ViT 图像分类，系统性地检验其**解码器无关性**。
- **整体含义**：研究试图将 token 合并的有效性归因到**编码器**层面，并给出可迁移的部署指导（超参由什么决定、何时值得用）。

## 2. 方法论

### 2.1 核心思想
- G2TM 是一个**单一、插入式**模块，只在 ViT 编码器的某个浅层 Transformer block 中插入**一次**（通常 i = 1 或 2），不同于多数方法在多层迭代式合并。
- 将 token 序列建模为**图**，只在**空间相邻且语义相似**的 token 之间融合，既降冗余又保持表征多样性；插入越浅，后续自注意力节省越大。

### 2.2 关键技术细节与流程
- **图构建**：无向图 \(G=(V,E,W)\)，顶点为 token，边连接空间相邻 token，权重为 token 嵌入的**余弦相似度**：
  \[
  cs_{i,j}=\frac{t_i\cdot t_j}{\max(\|t_i\|_2\|t_j\|_2,\epsilon)}
  \]
  仅计算每个 token 与**右侧、下方**邻居的相似度以避免冗余（等价覆盖 4-邻域）。
- **动态边割**：设定阈值 \(\tau\)，剪除权重低于 \(\tau\) 的边，图被划分为若干**连通分量**；用 BFS 找出规模 > 1 的连通分量及其 token 索引（供后续反合并使用）。
- **Token 融合**：对每个连通分量内的 token 做**无权重平均**得到代表 token \(\bar{t}_j\)，替换原 token，输出序列长度 \(N'\le N\)；未被连接的 token 原样保留。
- **训练 vs 推理的差异**：
  - 训练时为保持 batch 内序列长度一致，**不实际删除 token**，而是用**掩码自注意力**屏蔽被合并 token（仅保留代表 token），训练后复制代表 token 回各原始位置（反合并）。
  - 推理时（batch size=1）真正**移除**被合并 token，仅保留代表 token，从而获得实际加速与显存节省。
- **反合并（unmerging）**：对依赖空间操作的解码器（上采样、卷积）必须在解码前恢复全分辨率序列（Option 2）；Transformer 型解码器可直接处理稀疏序列（Option 1）。
- **阈值课程学习（curriculum）**：训练初期用较大 \(\tau\)，按 0.01 逐步下调至目标值，兼顾早期稳定性与后期性能。文中区分 **G2TM**（固定阈值）与 **G2TM†**（课程训练）。

## 6. 主要结论与发现

- **解码器无关性**：给定骨干规模，G2TM 在不同解码器下的**剩余 token 数与融合模式高度一致**，精度-效率权衡也一致 → 其有效性是**编码器的属性**，而非解码器的属性；一套超参可跨解码器迁移。
- **效率收益**：ADE20K 分割上 GFLOPs 稳定下降 **22–47%**，吞吐最高提升 **74%**，mIoU 退化在至少一种设置下 ≤ 2 点；EoMT 退化最小（≤ 0.3 点）。
- **分类泛化更好**：ImageNet-1k 上 Top-1 最多仅降 **0.7 点**，GFLOPs 降 22–35%，吞吐最高升 33%。
- **超参由什么决定**：
  - 最优超参主要取决于**骨干预训练配方**与**目标数据集**，而非解码器；
  - **插入层**偏好随骨干规模变化：T/S/B 倾向第 2 层，L 骨干反而在第 1 层更好（因大模型 token 表示更快同质化）；
  - **分辨率变化不需要重新调参**，但**换数据集需要重新调参**（ADE20K 用 0.88，Cityscapes 用 0.95）。
- **吞吐门槛效应**：当基线吞吐**高于约 100 FPS** 时，G2TM 自身的合并开销无法被后续注意力节省抵消，吞吐反而下降（尽管 GFLOPs 确实降低）；低于该门槛时才获得预期加速。
- **预训练影响显著**：DINOv2 预训练权重的 token 余弦相似度几乎全集中在 0.99–1.0，导致阈值判据失去区分度，mIoU 最大跌幅达 8.8 点；AugReg 则退化极小。
- **比例注意力（PA）任务条件化**：PA 在分类上略有益，但在分割上一致有害，建议分类启用、密集预测禁用。
- **免微调部署**：分类任务可容忍 off-the-shelf G2TM，分割任务一般需微调，仅 ViT-L 骨干例外。

## 7. 优点

- **问题定位清晰**：把"合并机制的收益 vs. 解码器的贡献"这一被忽视的归因问题显式提出并系统回答，具有方法论价值。
- **实验设计系统且控制严格**：跨 3 框架、3 解码器家族、4 骨干规模、3 数据集/多分辨率的矩阵式评测，统一骨干初始化，横向可比性强。
- **同时报告理论（GFLOPs）与实测（FPS）指标**，并诚实指出"GFLOPs 降但吞吐不升"的边界情形，避免了常见的片面结论。
- **实用指导性强**：给出可操作结论——超参按"预训练配方 + 数据集"调、按"骨干规模"选插入层、按吞吐门槛决定是否值得用、PA 按任务取舍。
- **分析工具可迁移**：用**token 余弦相似度分布**作为判断"某层是否值得做相似度合并"的诊断工具，具有通用参考价值。
- **定性可视化**支持定量结论：融合区域与语义均质区域（天空、外墙）对应，边界与小物体被保留。

## 8. 不足与局限

- **算力信息不完整**：未报告训练 GPU 型号/数量/时长，复现与成本评估困难；仅给出推理端单卡 A100 设置。
- **任务覆盖有限**：除分类外，密集预测仅覆盖**语义分割**，未涉及检测、实例/全景分割、深度估计等其他密集任务，泛化性结论的外推需谨慎。
- **骨干与架构范围受限**：仅评测**普通（plain）ViT** 与 patch size 16，未涉及层次化 ViT（如 Swin、SegFormer 类）或其他 patch 尺寸；EoMT 无显式解码器，其"解码器"定义带有一定人为设定。
- **数据集规模与偏差**：主要结论基于 ADE20K 与 Cityscapes，两者均以城市场景/室内场景为主，其他领域（医学、遥感等）适用性未验证。
- **强依赖预训练配方**：在 DINOv2 等自监督权重上退化剧烈，说明方法对 token 表示分布敏感，限制了在自监督/大规模预训练模型上的直接应用。
- **存在调参成本**：阈值 \(\tau\) 与插入层需按数据集和骨干重新验证，且使用阈值课程训练，带来额外工程开销；论文未给出自动化调参方案。
- **小模型不友好**：轻量骨干（ViT-T/S、高吞吐模型）上吞吐反而下降，方法的适用范围存在明确边界。
- **公平性细节**：为统一比较将 EoMT 改用 AugReg 而非原论文的 DINOv2，虽有利于控制变量，但使 EoMT 结果与原始论文不完全可比；部分效率收益因解码器计算占比不同而难以直接横向比较。
