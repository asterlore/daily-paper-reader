## 摘要
生物发现需要利用分子知识和新的测量来推断超出已观测条件的响应。我们提出 CellCanon，这是首个统一单细胞表达预测、基于证据的解释和观测驱动更新的智能体细胞世界模型。其预测核心在基因特异性数值读数之间复用条件级生物学证据，以指导单细胞表达生成。一个共享的世界状态将预测、获取的测量和来源关联的主张联系起来，支持解释与修正。在三种细胞系的 339 个留出 SciPlex3 条件上，CellCanon 将差异表达的 AUPRC 和 Macro-F1 分别较各指标最佳基线提升 63.3% 和 17.3%，并将方向 Macro-F1 提升 7.2%。在匹配的药物-细胞队列上，相对于逐基因推理，Predict 和 Explain 的实测语言模型 token 使用量分别下降 99.77% 和 98.41%。在基于来源的基准上，Explain 能以支撑性证明正确回答所有可回答问题，并识别所有证据不足的情况。在模拟实验反馈中，Update 对每种药物使用一个实测来源上下文，在不改变模型权重的情况下，在差异表达 AUPRC 和 Macro-F1 上超过最佳微调基线。这些能力共同支持对细胞响应的累积性刻画，并使预测和生物学判断能够随着证据积累而修正。

## Abstract
Biological discovery requires using molecular knowledge and new measurements to infer responses beyond the conditions already observed. We introduce CellCanon, the first agentic cellular world model to unify single-cell expression prediction, evidence-grounded explanation, and observation-driven updating. Its predictive core reuses condition-level biological evidence across gene-specific numerical readouts to guide single-cell expression generation. A shared world state links predictions, acquired measurements, and source-linked claims, supporting explanation and revision. On 339 held-out SciPlex3 conditions across three cell lines, CellCanon improves differential-expression AUPRC and Macro-F1 over the best baseline for each metric by 63.3% and 17.3%, respectively, and direction Macro-F1 by 7.2%. Relative to gene-wise reasoning on matched drug-cell cohorts, measured language-model token use falls by 99.77% for Predict and 98.41% for Explain. On the source-grounded benchmark, Explain correctly answers all answerable questions with supporting proofs and identifies all insufficient-evidence cases. In simulated experimental feedback, Update uses one measured source context per drug to exceed the best fine-tuned baselines in differential-expression AUPRC and Macro-F1 without changing model weights. Together, these capabilities support a cumulative account of cellular responses, with predictions and biological judgments that can be revised as evidence accumulates.

## 2. 方法论

### 2.1 核心思想：共享世界状态
- 定义查询状态 \(S_q^{(t)} = (\hat{y}_q^{(t)}, p_q^{DE,(t)}, p_q^{up,(t)}, E_q, C_q^{(t)}, O_t)\)，其中 \(E_q\) 为来源关联证据，\(C_q^{(t)}\) 为带依赖关系的声明，\(O_t\) 为已获取测量。
- 三类角色分工：**语言模型解读证据、工具核查引用与路径、数值模型预测与更新**；预测、测量、声明通过同一状态互相链接，支持解释与修订。

### 2.2 Predict（预测）
- **证据编译**：LLM（DeepSeek-V4-Flash）为每个条件选择至多 3 个靶点，标注相关性（高/中/低/未知权重 1/0.5/0.1/0.25）、作用范围（结合/功能作用/背景调控/对照表达），并保留来源 ID。
- **编码**：冻结的 Qwen3-Embedding-0.6B 生成文本嵌入，与结构化特征拼接后经投影归一化得到 96 维 \(z_q = P_{tr}(x_q)\)，该表示**在基因间共享**。
- **知识条件检索**：为每个训练药物构建 atlas（连续响应 2000 维 + DE 标签 2931 维 + 上调标签乘积 2931 维，共 7862 维），检索打分结合学习到的兼容性与化学/靶点/MoA 三类相似度：
  \[
  \ell_{di,c} = \frac{q_{dc}^\top k_{ic}}{\sqrt{H}} + \sum_{r=1}^{3}\text{softplus}(w_r)s_r(d,i),\quad \alpha = \text{softmax}(\ell)
  \]
  再经门控融合与 LayerNorm 得到 \(h_{dc}\)，由细胞特异 MLP 生成共享读数表示 \(u_{dc}\)。
- **三类读数独立监督**：
  - 连续响应：\(\hat{y}_{dc} = \mu_c + s_y\,\text{MLP}^{RNA}_c(u_{dc})\)，MSE 训练；
  - DE 与 DIR：冻结表示后拟合**基因特异性正则化逻辑回归头** \(p^{DE}_{dcg} = \sigma(b^{DE}_{cg} + \beta^{DE\top}_{cg}u_{dc})\)，方向头仅用训练 DE 样本监督。
- **条件级 DE 数量解码**：用验证集拟合 ridge 模型预测 DE 比例，据此选择 top 概率基因并分配方向。
- **概率引导的单细胞生成**：以匹配 DMSO 细胞为起点，依据 DE 置信度与方向概率进行有界响应修正（公式 7–9：相对置信权重 \(w\)、均值专家 \(m^\pm\)、检测专家 \(q^\pm\)），最终对生成群体做差异检验得到 DE/DIR。

### 2.3 Explain（解释）
- 对靶点作用、对照细胞表达、调控路径、来源陈述给出 **supported / contradicted / insufficient evidence** 三分类判断，附引用与自然语言理由。
- 工具枚举**未知符号边**的联合一致赋值，区分"所有符号赋值下都成立"与"依赖未解析相互作用"的结论；LLM 选择并排序候选路径。
- **局部状态批评器**提供定位诊断（如把"矛盾"降级为"证据不足"）；**转移验证器**检查问题覆盖、来源与路径一致性；声明带依赖关系，新测量可使声明变为可回答，来源撤回可移除支撑。

### 2.4 Update（更新）
- 环境揭示某药物在**一个源细胞上下文**的实测响应（2000 基因连续值 + 2931 基因 DE/DIR 标签）。
- 用**核岭回归**融合源响应相似性与化学/生物相似性，将响应迁移到未测目标细胞：
  \[
  K(i,j) = k_{RNA}(r_i,r_j)\big[(1-\eta)+\eta\,k_{drug}(i,j)\big],\quad \hat{y}^{transfer}_{dc} = \bar{y}_c + k_{d,0}^\top(K_0+\lambda I)^{-1}(Y_c - \mathbf{1}\bar{y}_c^\top)
  \]
- DE 校正混合条件标签似然（平滑 200、强度 0.5）、交叉拟合残差更新（强度 0.25）与响应特征树（≤7 叶、强度 0.1）；DIR 仅用残差更新（强度 1、混合权重 0.25）；另用源活性 ridge 模型调整期望 DE 数量（父模型计数权重 0.75、源估计 0.25）。
- **关键点：父预测器、迁移映射与校正头权重全部冻结**，更新完全在推理时完成。

## 6. 主要结论与发现

1. **条件级证据共享 + 基因特异读数**能在显著降低 LLM token 消耗（>98%）的同时，取得大幅超越纯数值模型与逐基因 LLM 推理的 DE/DIR 分类性能。
2. **独立的任务头（连续/DE/DIR 分开监督）是必要的**：用连续响应分数直接推导 DE 会带来大幅性能下降（DE F1 0.81→0.45–0.53），说明响应幅度与差异表达发生是不同可学习目标。
3. **生物学注释与实测对照上下文均有实质贡献**，其中生物注释对分类影响最大，DMSO 上下文主要改善 Δ 相关。

## 7. 局限与批判性评价

### 7.1 数据与泛化层面
- **单一数据源**：全部主结果基于 SciPlex3（3 个癌细胞系、24 h、剂量合并）。细胞系数量少意味着"细胞特异 MLP"与"细胞特异逻辑头"的泛化能力几乎未被真正检验；对原代细胞、体内上下文、多时间点动力学、剂量–响应曲线的外推均无证据。
- **剂量信息被合并**：将多剂量合并为单一"药物–细胞响应"简化了任务，也使模型无法回答"剂量如何改变方向"这类实际最关心的问题，DIR 标签在合并后可能掩盖非单调剂量效应。
- **留出条件构成**：339 个留出条件对应 112 个规范药物，药物数远小于条件数，条件间存在共享药物带来的相关性；虽用药物级 bootstrap 缓解，但"新药物 + 新细胞系"的双重外推仍缺乏系统性评估（如完全未见的 MoA 类别）。
- **基因面板限制**：2000 高变基因 + 931 landmark 的评估面板使结论难以直接迁移到全转录组（约 2 万基因）；作者虽报告额外 931 基因影响很小，但未做全基因组规模的验证。

### 7.2 方法层面
- **对 LLM 证据编译的依赖**：条件级证据由 DeepSeek-V4-Flash 一次性编译（靶点、相关性权重、作用范围），这些**离散超参（1/0.5/0.1/0.25）由人工设定**，其敏感性未被系统消融；证据视图敏感性实验只比较"原始来源 vs LLM 编译"两端，未覆盖编译错误传播的下游影响。
- **解释基准的自建循环性**：966 题的参考答案由作者依据来源规则构建，且"561/561 全对、405/405 全弃答"这种满分结果本身就是基准饱和的信号——它更多证明"系统与作者定义的规则一致"，而非"解释在生物学上正确"。缺少独立标注者、缺少与人类专家的一致性（inter-annotator agreement）报告。
- **三分类读数的耦合假设**：DE 数量由 ridge 解码、方向按概率分配、再经有界修正生成细胞，多个后处理环节（top-k 选择、置信权重、专家均值/检测专家）引入了较多未做全局敏感性分析的自由参数；消融显示各组件有贡献，但组件间交互未被拆解。
- **更新机制的经验性**：核岭迁移、混合似然（平滑 200、强度 0.5）、交叉拟合残差（0.25）、树模型（≤7 叶、0.1）、计数调整（0.75/0.25）等超参数量众多且缺乏推导或调参协议说明，可复现性依赖实现细节。
- **连续响应并非全面领先**：Top50 \(R^2\) 略低于 BioLORD，Δ-Pearson 的优势幅度（0.325 vs 0.254）远小于分类指标的差距；论文将叙事重心放在 DE/DIR 上是合理的选择，但也意味着**"连续表达预测"这一最经典任务上并未取得决定性改进**。

### 7.3 评估与报告层面
- **算力与成本披露不足**：未报告 GPU 型号/数量/训练时长，也未给出 API 调用费用；token 效率对比（-99.77%）虽亮眼，但绝对调用量（Predict 约 98 万、Explain 约 149 万 token）对应的实际开销与延迟未量化。
- **基线公平性**：外部基线微调仅搜索 2×2 的超参网格（lr 两档 × 更新数两档），而 CellCanon 的更新超参显然经过更多调试；"冻结 vs 微调"的对比因此可能部分反映调参投入差异而非范式差异。理想对照应是"同等调参预算下的微调"或"以 CellCanon 状态为输入的轻量适配器"。
- **统计报告**：主表以点估计为主，虽有配对 bootstrap 与 100 种子 Random 参照，但缺少对关键结论（如 DE AUPRC 领先幅度）的效应量与置信区间并列呈现，也未做多重比较校正。

## 8. 对领域的启示与可复用设计

1. **"条件级共享表征 + 基因特异轻量头"是可迁移的架构范式**：把昂贵的跨模态证据融合放在条件级（一次），把基因级判断交给正则化线性头（数千个），在样本稀缺的扰动预测场景中比逐基因推理更符合数据效率。
2. **把"测量"作为一等状态而非训练信号**：推理时可检索、可撤回的观测条目，使系统具备增量演化能力，同时保留审计线索——这对需要监管与复核的生物医学应用（药物重定位、毒性预警）具有直接价值。
3. **"弃答"应作为一等输出**：405 个证据不足问题全部正确弃答，配合"矛盾→证据不足"的降级机制，为 LLM 参与的科研系统提供了可操作的不确定性表达方式。
4. **符号不确定性下的联合赋值检验**是一个通用技巧：当调控图中存在未知符号边时，枚举一致赋值以区分"必然成立"与"依赖未解析交互"，可推广到任何不完整知识图谱上的推理。
5. **评估设计值得借鉴**：药物级 bootstrap、绝对分与增量分双表、多预算观测曲线、配对 bootstrap 区间，这套组合能有效抑制单数据集小样本评测中常见的乐观偏差。

## 9. 一句话总评

CellCanon 以一个可检查、可修订的共享细胞世界状态，把"数值预测—证据解释—观测更新"三条此前割裂的路线缝合起来，在 SciPlex3 上以极低的 LLM token 成本取得显著的 DE/DIR 分类提升，并展示了冻结父模型下的高效在线适应；其主要短板在于单一数据集与自建解释基准带来的外部效度疑问、剂量与全转录组维度的缺失，以及算力与超参透明度的不足——它更像一个**有说服力的范式论证**，而非一个已被充分验证的虚拟细胞通用求解器。
