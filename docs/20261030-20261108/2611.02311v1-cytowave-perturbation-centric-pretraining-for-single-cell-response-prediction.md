## 摘要
从单细胞数据中预测扰动下的基因表达是建模细胞响应的基础任务，在发现基因功能和设计治疗药物方面具有应用价值。然而，由于实验方案、生物学背景和物种差异，现有方法往往难以跨数据集泛化。我们提出 CytoWave，一个以扰动为中心的单细胞遗传扰动响应预测预训练框架。我们利用通过同源关系统一的大规模跨物种扰动数据集，并以两阶段方式训练 CytoWave。第一阶段，我们通过对未扰动细胞进行掩码基因表达恢复来学习参考对照细胞状态。第二阶段，我们预训练模型在给定对照状态和扰动信号的条件下预测扰动后的基因表达，并结合一个对比目标，使扰动响应的潜在表示与扰动信号对齐。我们在多种条件组合下进行严格的数据集留出评估，并开展通路活性变化的案例研究，证明 CytoWave 在预测单细胞遗传扰动响应方面具有一致且有效的性能。

## Abstract
Predicting gene expression under perturbations from single-cell data is a fundamental task for modeling cellular responses, with applications in discovering gene function and designing therapeutics. However, existing methods often struggle to generalize across datasets due to differences in experimental protocols, biological contexts, and species. We present \textbf{CytoWave}, a perturbation-centric pretraining framework for single-cell genetic perturbation response prediction. We leverage large-scale cross-species perturbation datasets unified via orthology and train CytoWave in a two-stage manner. In the first stage, we learn reference control cell states via masked gene expression recovery on unperturbed cells. In the second stage, we pretrain the model to predict perturbed gene expression given control states and perturbation signals, together with a contrastive objective that aligns latent representations of perturbation responses with perturbation signals. We perform strict dataset-held-out evaluation across multiple condition combinations and case studies of pathway activity changes, demonstrating consistent and effective performance of CytoWave in predicting single-cell genetic perturbation responses.

## 1. 核心问题与研究背景

- **任务定位**：从单细胞数据预测遗传扰动后的基因表达（Perturb-seq / CRISPR 筛选），是刻画基因功能、调控关系与细胞响应的基础任务，服务于功能基因组学与治疗靶点发现。
- **核心痛点**：现有方法多在**单一数据集/实验条件**下监督训练，或把通用单细胞模型迁移到扰动任务上微调，因而受实验协议、生物背景（细胞类型、刺激条件）与物种差异制约，**跨数据集泛化能力差**。
- **数据机遇**：CRISPR 扰动数据在基因覆盖度、测序深度与实验条件多样性上快速积累，使"以扰动为中心"的大规模预训练成为可能。
- **科学假设**：扰动响应由**初始细胞状态 + 扰动信号**共同决定；扰动通过共享的基因调控程序传播，产生全局而非孤立的表达变化。因此应在**共享潜空间**中参数化"扰动导致的潜状态变化"，而非逐数据集拟合条件回归。

## 2. 方法论

### 2.1 统一数据基础
- 收集 **19 项研究、42 个数据集、人+小鼠两物种、约 2470 万细胞**。
- 基因标识统一：基因符号 → Ensembl ID（HGNC / MGI+GRCm39）→ **Ensembl Compara 同源组（release 115）**，无同源分配的基因剔除；扰动靶标同样映射到同源空间。
- 元数据标准化为固定 schema 的离散 token：物种、细胞背景、细胞系、谱系、扰动技术、疾病状态、刺激条件、刺激时长；缺失字段填默认 token。
- 存储：`.h5ad` → **zarr + CSR 稀疏矩阵**，支持流式、分块并行 I/O，并以 zarr 为"权威真值"做一致性校验。

### 2.2 模型架构（编码器–算子–解码器）
- **Tokenization**：基因与元数据共享 embedding 表，加角色 embedding 区分基因/元数据/扰动；表达值 log(1+x) 归一化后仅保留非零基因（稀疏 token）；表达幅值通过 **FiLM** 注入（`(γ,β)=MLP(v)`，`h=γ⊙Emb(g)+β+role`）；**不使用位置编码**，保证转录组集合的置换不变性。
- **编码器 E(·)**：L 层 Transformer 处理元数据+基因 token 的无序集合，均值池化得到细胞潜状态 `z ∈ R^d`。
- **扰动编码 S(·)**：对扰动基因集合的 embedding 做均值池化，天然支持多基因扰动且置换不变。
- **扰动算子 T(·)**：加性潜状态更新 `z̃ = z + t_θ([z; s])`，即用 MLP 预测"扰动引起的潜位移"。
- **查询式解码器 D(·)**：`q = z + Emb(g) + role`，经 MLP + softplus 输出单基因表达，支持任意基因子集的灵活解码。

### 2.3 两阶段自监督预训练
- **Stage 1（对照细胞状态建模）**：对未扰动细胞随机掩码 15% 表达基因，用掩码恢复的 MSE `L_ctrl` 学习与扰动无关的参考细胞状态表征。
- **Stage 2A（直接扰动响应预测）**：为每个扰动细胞匹配同条件对照细胞，由 `z̃ = T(E(x), S(u))` 解码扰动后表达，在 30% 采样基因（**优先取扰动后变化最大的 top-300 基因**，其余随机采样）上计算 MSE `L_expr`。
- **Stage 2B（反向扰动信号对齐）**：对扰动 token 以概率 ρu 掩码，得到观测子集 `u_obs` 与目标子集 `u_mask`；用真实扰动细胞的潜位移 `Δz = E(y)-E(x)` 与上下文 `[meta_state + S(u_obs)]` 经对齐头 R_ψ 预测扰动 embedding `ê`，用 **in-batch InfoNCE（τ=0.1，余弦相似度）** 对齐 `ê` 与目标扰动 embedding。
- **总目标**：`L_stage2 = L_expr + λ·L_align`，实现中 λ=5.0（对扰动恢复损失加权）。
- **下游微调**：沿用 Stage 2 的算子与解码器，解码全部目标基因；所有预训练基线也在留出集训练划分上微调。

## 6. 主要结论与发现

- **CytoWave-S2 在全部 5 个留出数据集、全部 3 个指标上取得最优或接近最优**，且在未刺激/刺激、密集覆盖、大规模筛选、跨物种等不同情形下表现稳定。
- **两阶段互补**：仅 Stage 1 已在多数指标上超过多数基线，说明大规模对照细胞预训练提供了扎实的转录状态基础；Stage 2 的扰动感知学习在所有指标上进一步提升（如 GasperiniShendure2019 MAE 1.298→1.133，ΔPCC 0.108→0.112）。

- **预训练策略差异显著**：以未扰动图谱预训练为主的模型（scGPT、GeneFormer、GenePert、scouter）在 ΔPCC/ΔPCC20 上普遍接近 0 甚至为负，而以扰动数据为中心的预训练（含 LPM、CPA）明显更好，支持"扰动数据是更丰富训练信号"的核心论点。
- **通路级一致性**：预测的 Hallmark 通路活性在相对排序与绝对动态范围上均与真值高度吻合，说明模型未把活性坍缩到全局均值，捕获了结构化生物响应。

## 7. 优点

- **数据工程扎实**：同源基因对齐 + 固定元数据 schema + zarr/CSR 稀疏表示 + 严格的 h5ad↔zarr 一致性校验，为跨物种、跨研究预训练提供了可复现底座。
- **建模范式清晰**：把扰动建模为"潜空间加性位移"，将细胞状态与扰动效应解耦，天然支持多基因扰动与任意基因子集解码，参数量与计算量可控。
- **双向学习目标有巧思**：正向预测表达 + 反向从潜位移预测被掩码的扰动身份，使潜位移"锚定"在扰动信号上，缓解潜空间漂移/退化解。
- **架构细节讲究**：FiLM 保留连续表达幅值、无位置编码保证置换不变、长度分桶 + SDPA 降低变长序列填充开销、解码器末层零初始化稳定早期训练。

- **生物学验证到位**：不止于相关性数字，用 AUCell 通路活性同时检验 Δ 活性与绝对活性景观，提升结论可信度。

## 9. 对领域的启示与后续方向

- **"以扰动为中心"的预训练范式值得推广**：结果清楚显示，未扰动单细胞图谱预训练（scGPT/GeneFormer 类）在扰动响应预测上迁移有限，而纳入扰动数据（含 LPM、CPA）显著更好。这提示社区应把 Perturb-seq 语料本身作为预训练主体，而非仅作为下游微调任务。
- **潜空间加性算子是性价比较高的归纳偏置**：相比生成式/扩散式建模，加性位移参数量小、训练稳定、天然支持集合输入与任意基因子集解码，为后续引入更强表达分布建模（如 flow matching、负二项/零膨胀似然）提供了简洁基线。
- **双向目标可缓解表征退化**：正向表达预测与反向扰动身份对齐的组合，实质上是给潜位移施加"可识别性"约束，这一思路可迁移到其他条件响应建模（药物、环境刺激、时间序列）。
- **数据标准化本身是贡献**：同源组映射 + 固定元数据 schema + zarr/CSR 的工程实践，为跨研究、跨物种扰动学习提供了可复用的数据底座，其价值不亚于模型本身。
- **可跟进的实验方向**：
  1. 显式的**未见扰动 zero-shot 划分**与组合扰动基准；
  2. 对对齐项、FiLM、掩码策略等做**系统性消融与敏感性曲线**；
  3. 引入**通路/调控网络先验或因果正则**，提升机制可解释性；
  4. 报告**算力–性能缩放曲线**，降低复现门槛；
  5. 加入**批次混杂诊断与去偏**、以及统计显著性检验；
  6. 用**定向生物学验证**（标记基因、已知调控轴）替代或补充通用通路相关性。

## 10. 总体评价

CytoWave 是一篇**工程与范式并重**的工作：其核心贡献不在于单点精度突破，而在于提出并验证了"扰动数据大规模预训练 + 潜空间加性扰动算子 + 正反向联合目标"这一可扩展框架，并以严格的 dataset-held-out 协议和跨物种、跨模态的多样化留出集证明了跨数据集泛化的可行性。论文的数据治理与评估设计较为严谨，局限性陈述也较为诚实。主要短板在于预测精度的绝对水平仍有限、组合扰动与机制约束缺失、关键设计的消融与敏感性分析不充分，以及较高的算力门槛。总体而言，它更适合被视为**扰动响应预测领域的强基线范式与数据基础设施**，而非可直接用于生物学发现的成熟预测器；其提出的问题（如何让潜位移可识别、如何跨协议去混杂、如何走向组合扰动）构成了后续研究清晰的路线图。
